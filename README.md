# Автоматизация ML-пайплайна с использованием Apache Airflow

## Описание проекта
Проект посвящен построению автоматизированного пайплайна (MLOps) для регулярного обучения модели машинного обучения и генерации предсказаний на новых данных. В качестве оркестратора процессов используется **Apache Airflow** в связке с **Docker**.

## Архитектура и этапы пайплайна
Пайплайн состоит из двух последовательных шагов (тасков), управляемых через Airflow DAG:
1. **Pipeline (`pipeline`):** Загрузка тренировочных данных, обучение ML-модели, оценка качества и сохранение обученного пайплайна на диск в формате `pickle`.
2. **Predict (`predict`):** Загрузка сохраненной модели, обработка тестовых данных из папки `data/test`, формирование предсказаний и сохранение итогового DataFrame в CSV-формат в папку `data/predictions`.

## Используемый стек
* **Оркестрация:** Apache Airflow, Docker, Docker Compose
* **Язык:** Python
* **Библиотеки:** Scikit-learn, Pandas, NumPy, Logging

## Структура репозитория
* `dags/` — содержит файлы DAG для планировщика Airflow (`hw_dag.py`).
* `modules/` — исполняемые скрипты логики (`pipeline.py` и `predict.py`).
* `.gitignore` — файл конфигурации для исключения служебных файлов и локальных датасетов из индекса Git.
